## 实验日志（边做边记）

### 2026-08-15 · 环境与初步实验

**环境**：Win11 + Python 3.13 + venv。τ-bench 从 GitHub 源码装（PyPI 无包，GitHub 直连需镜像）。Windows 控制台需 `PYTHONUTF8=1`。

**基线（无策略库，test split 任务 0-30，DeepSeek-chat 同时做执行和用户模拟）**：pass^1 = **0.70**（21/30）。

**自进化 v1（同一批 30 任务，边做边学）**：0.767（23/30）。逐任务翻转：+4 修复 / -1 损坏 / -1 网络超时。策略质量人工检查合格（抽象、无泄漏）。

**正式对照（topk vs off × 2 seeds，30 任务）**：
- topk: 0.767, 0.767（均值 0.767）
- off:   0.800, 0.767（均值 0.784）
- 逐任务：topk 赢 5 / 输 7 / 平 18 → **当前设计下无稳定提升**

**教训与发现**：
1. 评测方差大（模拟用户 LLM 随机性），同一任务跨运行时过时不过；结论必须多 seed
2. 任务难度分布不均（两个 seed 的前/后半段通过率完全颠倒），分段对比无意义，必须同任务对照
3. 在线"边学边考"协议有缺陷：学习样本太少且和考题混淆 → 改用 **train(500)学 / test(115)考** 的先学后考协议（与 ReasoningBank 论文一致）
4. DeepSeek-chat 在零售域本身较强（0.77-0.80），简单任务上策略库无从发挥；提升空间可能在难题和弱模型上（待验证：Qwen3-8B 迁移实验）

**进行中**：learn80（80 个 train 任务学策略库）→ batch2（冻结策略库，60 个 test 任务，topk vs off × 2 seeds）

### 2026-08-15 · 最终主实验（先学后考协议）

**协议**：learn80（80 个 train 任务裸跑+提炼，bank 71 条）→ 冻结 bank → test 前 60 题 × 2 seeds × {冻结库 vs 无库}。

**原始结果**：frozen 0.750/0.783（均值 0.767）vs none 0.667/0.800（均值 0.734）。
**干净结果**（剔除 none_s10 的 4 个网络错误任务后，56 题）：
- frozen：0.750 / 0.786，均值 **0.768**
- none：0.714 / 0.821，均值 **0.768**
- 逐任务配对：**赢 7 / 输 7 / 平 42** —— 完全的硬币

**结论（负结果）**：在 τ-bench 零售域 + DeepSeek-chat 上，冻结策略库**无可测量的提升**。原始 +3.3pp 全部来自对照组网络错误。

**为什么可能无效（假设，待验证）**：
1. DeepSeek-chat 在该域已较强（裸跑 0.85/0.80），wiki 政策文档已覆盖大部分策略内容（提纯出的"先核实身份再改单"本就是政策原文的复述）——天花板效应
2. τ-bench 任务短视界（平均 5-8 轮工具调用），策略记忆的增益场景是长视界、易犯重复错误的任务（ReasoningBank 的增益多在 WebArena 类任务上）

**下一步假设：弱模型才是策略库的用武之地**——强模型（DeepSeek）学到的经验注入弱模型（Qwen3-8B，4090 本地），
若弱模型裸跑明显更差且注入后显著回升，则"经验跨模型迁移"成立，这是更有价值的故事。

### 2026-08-15 · 项目收尾

主实验（负结果）后评估了延伸方向（弱模型迁移、适用边界刻画），最终按"严谨实证研究"定位收尾。
